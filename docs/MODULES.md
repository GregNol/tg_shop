# Модули проекта — краткое описание

Этот файл содержит сводные описания ключевых модулей в проекте, чтобы быстрее ориентироваться в кодовой базе.

## services/

- `fragment_sender.py` — класс `FragmentSender` реализует пошаговую логику покупки и отправки Stars/Premium через Fragment.com: поиск получателя, инициация запроса, получение транзакции и отправка TON-транзакции через TON API. Также проверяет баланс TON-кошелька и уведомляет админов.

- `fragment_auth.py` — вспомогательный класс `FragmentAuth` для проверки авторизации на Fragment, получения баланса (частично реализовано) и обновления/проверки токенов.

- `ton_api.py` — утилита `get_ton_balance` для получения баланса кошелька через публичное API (toncenter).

- `repository.py` — `Repository` — слой доступа к базе данных (asyncpg). Содержит большое количество методов: работа с пользователями, платежами, историей покупок, промокодами, статистикой, VPN-подписками и пр. Служит единой точкой для операций с БД.

- `profit_calculator.py` — `ProfitCalculator` — получение курса TON/RUB (Coingecko) и расчёт себестоимости и прибыли для продаж Stars и Premium.

- `star_pricing.py` — `StarPricingService` — логика определения цены за звезду: статический/динамический режим, кэширование курса, получение котировок через Fragment и учёт комиссий.

- `remnawave.py` — клиент Remnawave Panel API (Bearer-токен): создание/обновление/удаление пользователей, назначение в squads, получение `subscriptionUrl`. Используется для управления VPN-подписками.

## payments/

- `cryptobot_payment.py` — интегратор CryptoBot: создание инвойсов, получение курсов, конвертация RUB→крипто, проверка статуса платежа. Кэширует курсы.

- `lolz_payment.py` — интеграция с API Lolz (HTTP): создание инвойса и проверка статуса.

- `lolz_payment_official.py` — обёртка над официальной библиотекой `lolzteam` (если установлена). Альтернатива `lolz_payment.py`.

- `crystalpay_payment.py` — клиенты для CrystalPay API: создание инвойса и проверка статуса.

- `rolly_payment.py` — интеграция с RollyPay (через библиотеку `rollypay`), создание инвойсов и проверка статуса.

- `xrocet_payment.py` — интеграция с xRocket/xRocet для выставления TONCOIN-инвойсов и проверки статуса.

- `yookassa_payment.py` — адаптер для YooKassa (создание платежей через v3 API и проверка статуса).

Каждый адаптер предоставляет унифицированные методы вроде `create_invoice(...)` и `check_payment_status(...)`/`check_payment(...)`, возвращая стандартизированный словарь/результат для использования в общей логике обработки платежей.

## handlers/

### admin/

- `panel.py` — основная админ-панель: команды/кнопки для статистики, экспорта истории, просмотра баланса TON, перехода в другие разделы.

- `broadcast.py` — конструктор и отправка рассылок: сбор сообщения, предпросмотр, фоновая отправка всем пользователям.

- `fragment_status.py` — страница статуса интеграции с Fragment: авторизация, баланс, обновление токена.

- `price_control.py` — управление ценами (Stars, Premium, VPN): просмотр текущих настроек, переключение динамического режима, редактирование значений.

- `promos.py` — создание/редактирование/удаление промокодов и просмотр статистики по ним.

- `settings.py` — общие настройки бота: тексты, поддержка, канал новостей, режим тех.работ.

- `user_management.py` — операции управления пользователями: поиск, выдача/списание баланса, выдача VPN-подписок, блокировка, просмотр истории покупок.

### user/

- `start.py` — стартовый сценарий и отображение основного меню, проверка и принятие условий (ToS), проверка подписки на канал.

- `purchase_stars.py` — весь flow покупки звёзд: выбор пакета/количества, расчёт цены, списание баланса, вызов `FragmentSender` для покупки/доставки и запись в историю.

- `purchase_premium.py` — аналогичный flow для покупки Telegram Premium (подарок/самому себе).

- `profile.py` — управление профилем пользователя, пополнение баланса, просмотр истории и т.д.

- `calculator.py` — калькулятор стоимости/профита для пользователей (если применяется в UI).

- `vpn.py` — операции связанные с VPN-подписками (покупка, управление), интеграция с `remnawave` и `repository`.
