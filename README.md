# TG Shop — Telegram Stars & Premium Bot

Многофункциональный Telegram-бот для продажи Telegram Stars и Premium-подписок с автоматической покупкой и доставкой через Fragment.com.

**Кратко:** продаёт Stars и Premium, принимает платежи несколькими сервисами, автоматически выполняет транзакции через Fragment и предоставляет мощную админ-панель для управления и мониторинга.

---

## 🔥 Возможности

- **Покупка Stars** — пакеты и произвольное количество; отправка себе или в подарок.
- **Покупка Telegram Premium** — покупки на 3/6/12 месяцев.
- **Множественные платёжные шлюзы** — CryptoBot, LolzTeam, CrystalPay и др.
- **Промокоды** — создание и применение скидок/бонусов.
- **Админ-панель** — управление пользователями, рассылки, мониторинг продаж и балансов.
- **Fragment интеграция** — автоматическая покупка и отправка через Fragment.com.
- **Логирование и мониторинг** — подробные логи операций и уведомления админов.

## 🚀 Быстрый старт (локально)

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <repo-url>
cd tg_shop
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. Настройте окружение. Основные переменные (пример):

- `BOT_TOKEN` — токен Telegram-бота
- `DATABASE_URL` — строка соединения с БД
- `FRAGMENT_API_KEY` / `FRAGMENT_COOKIES` — данные для Fragment
- `TON_SEED` / `TON_WALLET` — seed-фраза или ключ TON для отправки транзакций
- `ADMIN_IDS` — список id администраторов

Подробности по настройке Fragment — в [FRAGMENT_SETUP.md](FRAGMENT_SETUP.md).

4. Быстрый запуск:

```bash
python3 main.py
```

## Описание ключевых модулей

Ниже краткие описания папок и заметных модулей, чтобы быстрее вникнуть в код:

- `services/` — бизнес-логика и интеграции
	- `fragment_auth.py` — авторизация и получение токенов Fragment
	- `fragment_sender.py` — создание и управление покупками через Fragment
	- `ton_api.py` — взаимодействие с TON (создание и отправка транзакций)
	- `repository.py` — слой доступа к базе данных
	- `profit_calculator.py`, `star_pricing.py` — логика расчётов цен и прибыли

- `payments/` — адаптеры платёжных шлюзов
	- `cryptobot_payment.py`, `lolz_payment.py`, `crystalpay_payment.py`, `yookassa_payment.py` и др.
	- Каждый модуль реализует приём уведомлений/вебхуков и нормализует платёжные события для общего обработчика

- `handlers/` — обработчики Telegram-команд и состояний
	- `handlers/user/` — команды пользователей (покупки, профиль, старт)
	- `handlers/admin/` — админские команды (панель, статистика, рассылки)

- `utils/` — вспомогательные инструменты
	- `payment_balances.py`, `payment_checker.py` — проверка балансов платежных систем
	- `safe_message.py` — безопасная отправка сообщений (обёртки с обработкой ошибок)

- `scripts/` — вспомогательные скрипты (например, `vpn_expiry_notifier.py`)

## Сценарии деплоя

1) Docker / docker-compose (рекомендуется для большинства случаев):

```bash
docker-compose up --build -d
```

Убедитесь, что переменные окружения заданы в `.env` или в `docker-compose.yml`.

2) Systemd unit (пример) — для запуска `python3 main.py` как сервиса:

```ini
[Unit]
Description=TG Shop Bot
After=network.target

[Service]
User=botuser
WorkingDirectory=/path/to/tg_shop
EnvironmentFile=/path/to/tg_shop/.env
ExecStart=/path/to/venv/bin/python3 main.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

3) Рекомендации по безопасности и эксплуатации:
- Держите секреты в защищённом хранилище (Vault, SSM) или хотя бы в файле недоступном для коммита.
- Настройте логирование и ротацию логов.
